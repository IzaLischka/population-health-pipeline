# tools

Third party binaries used by this repository. Not tracked in git.

## synthea-with-dependencies.jar

Not required for the dataset currently checked into this repository
(see data/raw/synthea/SOURCE.md for how that dataset was sourced).

Kept here only if you want to experiment with local Synthea generation.
Download from the official release used by this project:
https://github.com/synthetichealth/synthea/releases/tag/v4.0.0

Save it as tools/synthea-with-dependencies.jar. Be aware of a known
Synthea failure mode documented in SOURCE.md before relying on local
generation for anything beyond experimentation.
